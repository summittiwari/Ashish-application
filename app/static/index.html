TRANSPARENT COVERAGE

Know what was assessed.

Match scores describe document agreement. Accuracy requires a labelled benchmark.

Native document checks

Character edits, numbers, polarity, text styles, page geometry, image pixels and encoding, native tables, vectors, metadata, forms, links and annotations.

Exact character boxes are used for native text. OCR highlights use the coordinates returned by the recognition model.

Explicit limits

General semantic equivalence is not guaranteed by rules. A PDF does not reliably identify its logos; supply known logo regions for a separate logo score.

Scanned font identities, dynamic XFA behavior, and cryptographic signature trust are not assessed. Authoring concepts such as CSS padding cannot be recovered exactly from a PDF.

OCR & resources

Surya runs locally when configured. No comparison LLM or cloud document API is used. Rendered pages are processed individually with pixel and memory limits.

Large-file capacity depends on page complexity, image resolution, available disk, RAM and worker limits.

Reviewable evidence

Every finding includes a category, old/new values, location, severity, confidence, and score contribution. Unassessed checks appear as N/A.

Original PDFs are preserved. Annotated PDFs and reports are separate downloads.
